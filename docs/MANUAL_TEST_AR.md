# قائمة فحص يدوي — لا تُعد نتائج اختبار

لمجرد وجود هذه القائمة لا يعني أن أي بند منها نُفذ. سجّل الجهاز وإصدار Android وإصدار التطبيق واسم الموقع وتاريخ الاختبار والنتيجة والأخطاء؛ لا تُدرج أسرارًا.

- [ ] تحقق من SHA-256، وثبّت APK وافتحه على هاتف أو محاكي.
- [ ] أدخل عنوان مزود API واسم النموذج والمفتاح داخل التطبيق؛ أغلق التطبيق وافتحه وتحقق أن المفتاح لم يعد ظاهرًا.
- [ ] افتح صفحة HTTPS عامة محددة، وسجل نتيجة التحميل والنطاق والموقع.
- [ ] إذا دعم الموقع تسجيل الدخول في WebView، سجّل الدخول يدويًا. اختبر الانتقال إلى وضع التحكم اليدوي عند ظهور نموذج كلمة مرور أو CAPTCHA، مع تذكر أن الكشف تقريبي.
- [ ] استورد ملف Markdown أو نصًا، وأدخل قاعدة مشروع، وابدأ مهمة؛ تحقق من معاينة المقتطف ومصدره قبل إرساله.
- [ ] ارفض إجراءً وتحقق أن الوكيل يتوقف ولا يعيد تنفيذه بعد المتابعة.
- [ ] تولَّ التحكم وغير الصفحة ثم تابع؛ تحقق أن النقر والكتابة لا يستخدمان عناصر قديمة ويحتاجان قراءة جديدة وموافقة.
- [ ] ألغِ أثناء انتظار موافقة وتحقق من عدم بدء الإجراء بعدها. الإجراء الذي بدأ قبل الإلغاء قد ينتهي.
- [ ] احفظ ملفًا، وافتح قائمة النتائج، وصدّره يدويًا وتحقق من محتواه. هذا لا يختبر تشغيله.
- [ ] سجّل ما اختبرته وما فشل، وأي موقع أو جهاز لم تختبره. لا تنشر بيانات جلسة أو مفاتيح.

- اتصالات النموذج الخارجية قد تكون مدفوعة. حد التكلفة داخل التطبيق تقديري وليس حدًا ماليًا مضمونًا؛ اضبط حدًا لدى مزود الخدمة. البيانات المرسلة تتطلب موافقة موضحة داخل التطبيق.
